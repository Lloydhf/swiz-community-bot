# Portfolio case study

Status: working source with offline tests; deployment requires personal configuration.

The problem is coordinating a community through tickets, moderation and persistent event rosters. The useful design question is how to make administrative actions understandable while preventing duplicate or unauthorized actions. Review src/tickets.js, src/activities.js and test/core.test.js.
